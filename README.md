# ADHD Killer · PWA 基础版

无需安装 npm 依赖的静态 PWA，使用 HTML、CSS 和原生 JavaScript。基础交互已接通，不含 AI、后端或账号。

## 本地启动

在终端执行：

```sh
cd /Users/Apple/Documents/python_project/adhd
python3 -m http.server 8000 --bind 127.0.0.1
```

电脑浏览器打开 http://localhost:8000 。按 Control+C 停止。不要直接双击 index.html：安装和离线功能需要 HTTP 服务。

## 文件说明

- `index.html`：页面结构、移动端和 PWA 引用。
- `styles.css`：响应式样式。
- `app.js`：小时目标、每日 Todo、目的计时、会话历史、本地存储及 JSON 导出。
- `manifest.webmanifest`：应用名称、图标、启动地址与独立窗口设置。
- `sw.js`：缓存应用资源，支持成功访问并缓存后的离线打开。
- `icons/`：本地生成的 PNG 应用图标，包含 iPhone 图标。

## 已有功能

1. 保存当前小时目标、安排其他小时的目标。
2. 新增、完成、删除每日 Todo。
3. 记录使用目的并计时，支持延长、完成或未完成结束。
4. 查看当天已结束的计时记录、导出全部本地数据。
5. 适配手机屏幕、主屏幕安装、资源离线缓存。

日期按设备本地时区划分；跨天会话归属启动当天。历史数据保留，当前页面展示当天数据，全部数据可导出。记录为经过时间，不是自动识别的专注时间；暂不提供导入和手工修正。

## 部署与 iPhone 安装

将整个目录放在静态网站托管服务上，使用 HTTPS。无需后端或构建步骤，发布目录就是当前目录。支持根路径和 GitHub Pages 项目子目录；所有资源路径均为相对路径。

部署后，在 iPhone Safari 打开 HTTPS 链接，选择「分享 → 添加到主屏幕」（如有「作为网页 App 打开」选项，请开启）。安装后先联网打开一次，等待底部显示资源已缓存，再测试离线打开。

仅把文件推到 GitHub 不会自动部署。需要在仓库或托管平台另外启用网站发布。局域网 HTTP 地址可用于简单页面预览，但不等同于 localhost 安全环境，不能用于完整验证 PWA。

## 已知边界

- 数据保存在当前浏览器 localStorage，无云端同步；浏览器和主屏幕 App 可能拥有不同存储环境。清理站点数据可能丢失记录。
- 计时依据开始时间计算，刷新后可恢复。页面后台或锁屏时可能暂停执行；返回页面会重新计算，但不保证后台准时提醒。
- 本版的到时提示是页面内提示，没有系统推送、原生锁屏小组件或解锁拦截。
- AI 功能尚未接入。未来需在服务端保管模型密钥，不要写入前端或 GitHub。
- 离线仅覆盖应用静态资源。今后接入 API 时，应单独设计联网失败处理，不缓存敏感接口响应。
- 更新页面资源时需同时递增 sw.js 的 CACHE 版本；新缓存通常在旧页面全部关闭后启用，再次打开使用新版。

## 下一步建议

先用真实 iPhone 验证安装、关闭后重开、离线访问和存储，再考虑 AI 规划、数据同步与提醒服务。
