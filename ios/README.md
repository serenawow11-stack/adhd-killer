# 回到此刻 · iOS 自用原型

此工程是独立 SwiftUI App + ActivityKit 实时活动扩展。最低 iOS 17，建议 Xcode 16 或更高、且支持你手机的 iOS 版本。网页版保持不变，两者数据暂不互通。

## 锁屏显示

1. 当前小时目标，带具体时段。
2. 临时意图名称、开始/截止时间和系统倒计时（到零停止）。
3. 今日完成进度与最多 3 条未完成任务。完整清单在 App 中操作。

点击锁屏卡片打开 App，可修改、勾选、完成意图或延长 2 分钟。灵动岛设备也有简化显示。没有临时意图或任务时显示空状态。

## 第一次安装到自己的手机

1. 在 Mac 的 App Store 下载 Apple 的 Xcode，首次打开完成组件安装，安装 iOS 平台支持。
2. 双击 `ADHDKiller.xcodeproj`。
3. Xcode → Settings → Accounts 添加自己的 Apple Account（自己输入密码即可）。
4. 点击左侧蓝色项目图标，在 TARGETS 中分别选择 `ADHDKiller` 和 `FocusActivity`。
5. 两个 target 的 Signing & Capabilities 中都勾选 Automatically manage signing，Team 选择自己的 Personal Team。
6. 如果 Bundle Identifier 提示被占用，将 App 改为独一无二的标识，比如 `com.你的英文名.focusdemo`，扩展改为相同前缀加 `.activity`。
7. 用数据线连接 iPhone，在手机上信任电脑；按 Xcode 提示开启“设置 → 隐私与安全性 → 开发者模式”，必要时重启。开发者模式由你本人确认。
8. Xcode 顶部选择 ADHDKiller scheme 和你的 iPhone，点击 ▶ Run。若手机要求信任开发者，按照系统提示在“设置 → 通用 → VPN 与设备管理”中信任自己的开发者账号。
9. 在 App 中输入目标、添加今日任务、填写临时意图和时长，点击“开始意图并显示到锁屏”，然后锁屏查看。
10. 如不显示，在 iPhone 设置中找到本 App，检查是否允许实时活动。

免费 Personal Team 的签名有效期为 7 天；到期重新连接 Xcode 并 Run。请勿为重新签名删除 App，删除会丢失本地数据。不需要云端服务、推送证书或付费会员来编写和尝试这个本地原型；最终需在你的个人签名和真机环境验证。

## 当前边界

- 不是普通通知，不会响铃；意图倒计时由系统 Text(timerInterval:) 渲染，不依赖后台计时器。
- 没有远程推送、App Groups、iCloud 或登录；只用本机 UserDefaults。
- App 在前台会检测跨小时，回到前台也会更新；后台不能保证自动换小时目标。卡片显示明确时段，过期会标记需要打开 App 更新。
- 实时活动不是全天常驻：系统有持续时间限制，用户也能划掉，必要时重新开启。
- 新的一天只显示当天任务，旧任务仍留在本地存储；暂未提供历史页。
- 不监听设备解锁，不拦截其他 App。
- 本工程在没有完整 Xcode 的环境下生成；已检查 Swift 语法及工程 plist，尚未进行 iOS SDK 编译、模拟器布局和真机验证。

## 真机验收

- 添加 4 项任务，锁屏出现最多 3 项；完成一项后计数和下一项更新。
- 设置 1 分钟意图，锁屏倒计时到零停止；回 App 延长后恢复倒计时。
- 完成意图后显示无意图；结束实时活动后卡片消失。
- 强制退出再打开 App，数据保留；划掉卡片后可以重新开启。
- 跨小时/跨天回到 App，显示对应时段与当日任务。
- 大字体、小屏 iPhone 上检查卡片是否被截断（可能需压缩清单展示数量）。
